# Ключ подписи

`kino-release.jks` подписывает релизный APK. Пароль лежит рядом в
`keystore.properties`; оба файла в .gitignore и в репозиторий не попадают.

Ключ **нельзя терять**: Android ставит обновление поверх установленного
приложения только с той же подписью. Без ключа семье придётся удалять
приложение и ставить заново, теряя вход. Сделай копию обоих файлов в
надёжное место.
