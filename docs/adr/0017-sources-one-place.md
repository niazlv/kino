# ADR-0017. Площадка — одно описание; площадки-скрипты и правки от людей

**Статус:** принято · **Дата:** 2026-11-23 · Где лежат площадки и что из
этого протокол — ADR-0018 (пути ниже — уже по нему)

## Контекст

Площадки — расходники (домены, вёрстка, подписи меняются чаще, чем выходят
сборки). Локальный движок (ADR-0015) отдал платформу людям без сервера, и
смысл этого режима для нас — в двух вещах: доступ без сервера и то, что люди
сами добавляют площадки и присылают правки, а мы проверяем их и включаем на
сервере.

До этого решения площадка жила в пяти местах: пакет на Go, фабрика в
`bootstrap/providers`, списки «аниме» и «ищет по номерам», список источников
в Android (`EngineSources`) и переменные выкатки. Человек с телефона не мог
ни добавить площадку, ни починить сломанную: нужен Go, сборка APK и выкатка.
Конформанс-набор из ADR-0001 оставался заглушкой.

## Решение

### 1. Площадка описывает себя сама

`internal/adapter/providers/source`: `Spec` — id, имя, пометка для экрана,
вид (`general`/`anime`), «ищет по номерам», подсказка маршрута, настройки
(`Setting`: переменная, подпись, секрет, обязательна, служебная) и `New`.
Пакет площадки регистрирует его в `spec.go` (`source.Register` из `init`);
`providers/all` подключает пакеты одной строкой каждый, а
забытую строку ловит тест. Из реестра выводятся фабрика (`BuildRegistry`),
списки `AnimeProviders()`/`LookupProviders()`, экран источников в Android
(`GET /engine/sources`) и `sourcekit list`.

Площадка на Go = её пакет + `spec.go` + строка в `all.go`. Больше нигде.

### 2. Площадки-скрипты

Площадка может быть одним файлом JavaScript (`providers/sources/*.js` — вшиты в сборку;
`SOURCES_DIR` — поставленные на месте, перекрывают вшитые). Исполнитель —
goja (чистый Go, собирается и для телефона, cgo не нужен). Файл вызывает
`source({...})`: описание (то же, что `Spec`) и методы. Два пути:

- **свои потоки**: `search`, `title`, `episodes`, `resolve` (+ `voices`,
  `lookup`, `changed` по желанию) — скрипт сам отдаёт адрес HLS или MP4;
- **чужие плееры**: `search`, `title`, `players(id, серия)` — скрипт говорит,
  где Kodik, CVH или Alloha, а серии, озвучки, поток, разметку пропуска и
  кадры добывает общий код семейства «Джутсу» (`jutsu.NewSite` — тонкий мост
  поверх проверенного в бою кода, без перекройки его внутренностей).

Для платформы скрипт — обычный `appprov.Provider` под тем же `Spec`: реестр,
тикеты, шлюз, склейка, бережный режим движка его не различают. Граница
ADR-0002 цела: шлюз не знает ни площадок, ни скриптов.

**Песочница.** Сеть — только на хосты из `hosts` площадки и их поддомены,
включая редиректы; только http(s); настройки — только объявленные в
`settings` (на сервере в окружении лежат пароли); ни файлов, ни процессов;
каждый вызов ограничен сроком и прерывается посреди бесконечного цикла.
Запросы идут маршрутом площадки и считаются счётчиком движка. Чего
песочница НЕ даёт: ограничения памяти (goja его не умеет) — поэтому на
сервере работают только скрипты, которые мы прочли и приняли (ниже).

Скрипт может заменить встроенную площадку на Go с тем же id — так её чинят
без новой сборки, история и привязки (`external_refs` по id) сохраняются.
Вшитый в сборку скрипт с id встроенной площадки — ошибка (тест).

### 3. Исполняемый контракт

`internal/adapter/providers/providertest` — живые проверки: описание честно
(заявленные возможности реализованы), поиск находит, тайтл в канонической
форме (IMDb `tt…`, номера — числа, без HTML), несуществующий номер —
NotFound, серии без повторов, у фильма одна «серия» с сезоном 0, резолв
отдаёт http(s)-адрес, срок и `allowed_origins`, покрывающие хост потока, и
по желанию — начало самого потока. Один и тот же набор запускают
`cmd/sourcekit check`, движок на телефоне (`POST /engine/sources/check`) и
приём правки (`sourcekit import`). ADR-0001 обещал это как условие приёма
плагина — теперь оно исполняемое.

### 4. Путь правки: от человека к серверу

1. Человек в приложении («Локальный движок» → «Площадки») ставит файл
   площадки или правит сломанную, проверяет кнопкой «Проверить» и жмёт
   «Отправить нам»: файл `.js` и отчёт проверки уходят системным
   «Поделиться» — в мессенджер или почту. Отдельной инфраструктуры для
   приёма не нужно: наш сервер снаружи не виден, а файл доходит всегда.
2. Мы: `go run ./cmd/sourcekit import площадка.js -q "запрос"` — разбор,
   сверка версии с тем, что в `providers/sources/` (версия обязана вырасти), живые
   проверки, копия в `providers/sources/`. Дальше — обычное ревью: `git diff`, коммит.
3. Выкатка core и crawler уносит площадку на сервер (они читают вшитые
   `providers/sources/` и `SOURCES_DIR`); включение — строкой в `PROVIDERS`. Следующая
   сборка приложения несёт её всем движкам.

`version` в файле — обязательная `x.y[.z]`: по ней видно, какая правка новее.

### 5. Качалка — на любых данных

Манифест скачивания берёт протокол у источника: MP4 одним файлом —
`PROGRESSIVE` с адресом `/stream/{тикет}/file` (шлюз отдаёт его с докачкой
по Range), HLS — как раньше. Значит, любая площадка, которую видит плеер,
качается той же утилитой без строчки кода под площадку.

## Отвергнуто

- **Плагины на Go в рантайме** (`plugin`, go-plugin): не работают на Android
  и iOS, требуют той же версии компилятора.
- **WASM**: исходящий HTTP из WASI болезненный (как и в ADR-0001), а авторам
  площадок нужен язык, на котором пишут разбор страниц, — JavaScript.
- **Декларативное описание (селекторы в YAML)**: площадки слишком разные —
  подписи, распаковка плееров, JSON внутри скриптов страницы; описание
  быстро превращается в недоязык.
- **Lua/Starlark**: меньше людей умеют, нет нативного JSON и RegExp.
- **Приём правок на наш сервер напрямую**: он виден только из дома и через
  VPN; публичная ручка — новая поверхность атаки ради того, что «Поделиться»
  делает бесплатно. Можно добавить позже, не меняя формата: правка — это
  тот же файл.

## Следствия

- Новая площадка на Go — `spec.go` и строка в `all.go`; на JS — один файл в
  `providers/sources/` (заготовка: `sourcekit new <id> [-players]`).
- Приложение не держит список площадок: он приходит от движка.
- Сервер исполняет только принятые скрипты; устройство — любые, которые
  поставил его владелец (как и любое расширение браузера — на его совести, о
  чём сказано в отказе от ответственности локального режима).
- Справочник для автора площадки — `docs/script-sources.md`.
