# ADR-0013. Анилибрия и AniDub

**Статус:** принято · **Дата:** 2026-10-03

## Контекст

Семья смотрит аниме в озвучках Анилибрии и AniDub. Обе студии есть внутри
Kodik и CVH у AnimeGO (ADR-0008), но там это чужой плеер: Kodik отвечает
только российскому адресу, CVH привязывает ссылку к адресу резолва, а
разметки опенингов у CVH нет. У обеих студий своё видео — без посредников.

Сверено 2026-10-03.

**Анилибрия (AniLiberty).** Сайты anilibria.tv / anilibria.top /
aniliberty.top — витрины одного API `api.anilibria.app/api/v1`:

- каталог `/anime/catalog/releases` — ~1,9 тыс. релизов, по 50 на страницу,
  свежие сверху (`fresh_at`); поиск `/app/search/releases?query=`;
- релиз — один сезон, у него номер MAL и Shikimori;
- карточка `/anime/releases/{id}` — серии с `hls_480/720/1080`, длиной,
  кадром и разметкой `opening`/`ending` с того же файла;
- CDN `cache(-rfn).libria.fun`, ссылка без подписи и без привязки к адресу;
  в ссылке `isWithVideoAds=1`, но рекламы в плейлисте нет ни из
  Нидерландов, ни из России;
- API отвечает 403 «чужим» клиентам (python-urllib), браузеру — 200.

**AniDub.** Официальный online.anidub.com — DLE:

- запись — сезон, адрес `/index.php?newsid={номер}` уводит на slug;
- внешних номеров нет: русское название, ромадзи, «Сезон 3, серии 1 из
  24» (новая вёрстка) или «Рус / Romaji [28 из 28]» (старая), год;
- вкладка «ПЛЕЕР #1» — свой плеер на отдельном домене, в нём
  `PLAYER_CONTEXT` со всеми сериями; поток — `vid.php?v=…`: мастер на
  720p/480p, сегменты на `*.anivids.link` под AES-128, подпись на два
  часа, к адресу не привязана; CDN требует Referer или Origin плеера и
  браузерный User-Agent;
- основной домен из России не открывается (с сервера — таймаут), зеркало
  `v14.anidub.digital` открывается; номер зеркала меняется;
- карта сайта отстаёт на месяц, свежее — на ленте главной;
- Sibnet во вкладках отвечает 403 на любой запрос.

## Решение

1. Две площадки-провайдера: `anilibria` и `anidub`, обе — аниме-площадки
   (`AnimeProviders`: склейка «аниме только с аниме», досбор при открытии
   тайтла).
2. **anilibria** — по API. Склейка по MAL. Озвучка одна — вариант
   «AniLibria»: студия запоминается и подбирается на других площадках.
   Качество выбирается при резолве (плейлисты по качествам). Разметка
   серии едет в `Source.Segments` (ADR-0012), кадры — в списке серий.
   Обход по курсору — до первого релиза старше курсора.
3. **anidub** — разбор страниц. Склейка по названию, году и сезону — слабее
   MAL, но правила склейки консервативны («сомнение — новый тайтл»).
   Адресов сайта в настройке несколько (`ANIDUB_SITE`), ходим первым
   ответившим; молчащее зеркало ждём не дольше 10 с, если есть следующее.
   Поток — адрес `vid.php` с заголовками плеера в тикете: мастер с
   подписанными ссылками шлюз берёт сам, к площадке он по-прежнему
   не привязан (ADR-0002). Sibnet не подключён.
4. Обе — маршрутом `direct`: с сервера открываются без VPN.

## Последствия

- Шлюз и core не менялись, кроме списка площадок.
- Своей разметки у AniDub нет. AniSkip к его серии спрашивается по MAL
  другой площадки того же тайтла (ADR-0012), а годится — только при
  совпавшей длине файла; у дубляжа это бывает редко.
- Обход AniDub — страница на запись: полный — ~3 тыс. страниц с паузой
  0,4 с (около 20 минут), по курсору — две страницы ленты и записи с них.
