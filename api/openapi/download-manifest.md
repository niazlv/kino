# Манифест скачивания

Контракт между платформой и загрузчиком. Утилите **не нужна авторизация
площадки**: платформа уже сделала резолв, и все адреса в манифесте ведут
через её шлюз. Манифест отдаётся двумя путями:

- `GET /d/{token}` — по ссылке-разрешению с кнопки «Поделиться», без
  входа: сам токен и есть право доступа. У неё есть срок, отзыв и учёт
  обращений.
- `GET /api/v1/episodes/{episodeId}/manifest` — по сессии платформы, для
  обычной ссылки со страницы. Человек копирует адрес из браузера —
  `…/#/title/{titleId}`, серия `…/#/title/{titleId}/s{S}e{E}` (так адрес
  показывает страница во время просмотра) или по старому `…/{episodeId}`, —
  утилита
  входит его кукой `kino_session`, берёт серии из
  `GET /api/v1/titles/{titleId}` (`episodes[].id`, `seasonNo`, `episodeNo`,
  `durationSec`; у фильма `seasonNo` = 0), постер — из
  `GET /api/v1/titles/{titleId}/art`, и просит манифест на каждую серию.
  `select` здесь всегда пустой: что брать, человек говорит флагами утилиты.

  Площадку и озвучку здесь выбирают так же, как для плеера, — строкой
  запроса (утилита ходит GET):
  - `voice` — студия из общего списка озвучек, ключ из
    `GET /api/v1/episodes/{episodeId}/voices` (ADR-0011). У kinopub студии —
    дорожки одного потока, а у остальных площадок каждая студия — свой
    поток: без `voice` в файл попадает та, что у площадки первая. Студии у
    серии нет ни у одной площадки — манифест всё равно выдаётся, в той
    озвучке, что есть (скачивание сезона не должно рваться посреди), и
    `audios` её называет;
  - `source` — площадка-предпочтение (не строгий выбор: серии, которой у
    неё нет, лучше прийти с другой);
  - `avoid` — площадки через запятую или повтором параметра: идут в конец
    очереди (их поток только что сломался у этого человека).

  В ответе по сессии есть `source` — `{ "id": "lordfilm", "name": "ЛордФильм" }`,
  площадка, выдавшая поток.

```json
{
  "v": 1,
  "title": "Арифурэта: Сильнейший ремесленник в мире",
  "season": 3,
  "episode": 13,
  "filename": "Arifureta.S03E13",
  "protocol": "HLS",
  "url": "https://kino.example/stream/tkt_.../master.m3u8",
  "expiresAt": "2026-09-04T09:00:00Z",
  "audios":    [{ "id": "3991159", "language": "rus", "title": "AniLibria" }],
  "subtitles": [{ "id": "0", "language": "rus", "title": "rus" }],
  "renditions":[{ "height": 1080, "codec": "h264" }],
  "select": { "maxHeight": 1080, "audios": [], "subtitles": [] }
}
```

## Правила

`select` — что именно просили забрать. **Пустые списки означают «всё»:**
по умолчанию человек хочет полный файл, а сужение — осознанное действие.

`audios` — дорожки озвучки. У kinopub их называет и плейлист; у площадок,
где студия — отдельный поток, звук вшит в видео одной безымянной дорожкой,
и `audios` — одна запись с подписью выданной студии (язык `rus`; у
оригинала и варианта «с субтитрами» язык пустой — он неизвестен). Ею
загрузчику стоит подписать вшитую дорожку.

`subtitles` — только дорожки самого плейлиста. Субтитры, которые площадка
кладёт рядом отдельными файлами (ADR-0010), плеер витрины получает со
шлюза сам, а в манифест они не попадают: загрузчик берёт дорожки из
плейлиста, и выбрать то, чего там нет, он не сможет.

`url` уже содержит тикет и живёт ограниченное время; `expiresAt` —
момент, после которого манифест бесполезен. Загрузчику стоит начать
скачивание сразу, а не сохранять манифест на потом.

`protocol` — как качать. `HLS` — `url` ведёт на мастер-плейлист шлюза
(`/stream/{тикет}/master.m3u8`), дальше дорожки, качества и сегменты.
`PROGRESSIVE` — у источника один готовый файл (MP4 у Filmix, Sibnet,
площадок-скриптов со своими файлами): `url` ведёт на `/stream/{тикет}/file`,
шлюз отдаёт его целиком с докачкой по `Range`. Выбора дорожек и качества у
такого файла нет — что запечено, то и приходит; `audios` называет
вшитую дорожку, `renditions` — её высоту.

`filename` — предложение платформы, а не требование. Загрузчик вправе
раскладывать файлы по своей схеме.

Версия `v` растёт только при ломающих изменениях. Новые поля добавляются
без её изменения, поэтому неизвестные поля надо игнорировать.
